# Active learning for classification and follow-up on ZTF

**Wednesday November 11, 9:30–10:45** · Room 401-20 · Dimitrios Kourtesis

This session covers active learning, in which a model chooses which unlabeled objects are most informative to label next. Participants apply query strategies to ZTF alert embeddings and compare how quickly each strategy improves a classifier for a fixed labeling budget, which mirrors how spectroscopic follow-up is allocated.
