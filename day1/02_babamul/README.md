# Babamul: features, API usage, and alert filtering

**Monday November 9, lecture 10:25–11:05 and activity 1:15–2:30** · Room 401-20 · Thomas Culino

The lecture presents Babamul, the public deployment of BOOM, and its features. In the afternoon activity, participants use the Babamul API to query alerts and write filters that select candidates from the ZTF and Rubin alert streams.

Before the activity, copy `.env.example` to `.env` in this folder and fill in the three Babamul credentials from your profile page, as described in [`setup/README.md`](../../setup/README.md).
