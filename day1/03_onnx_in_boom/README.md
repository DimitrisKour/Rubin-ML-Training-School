# Running ML models in BOOM with ONNX

**Monday November 9, 1:15–2:30** · Room 401-20 · Sushant Sharma Chaudhary

This session shows how a trained model is exported to the ONNX format and run inside BOOM on incoming alerts. Participants inspect existing AppleCiDEr ONNX models, run them with ONNX Runtime, and follow the steps that take a model from training to the broker.
