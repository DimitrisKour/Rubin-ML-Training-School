# ZTF and Rubin alert streams with BOOM

**Monday November 9, lecture 9:45–10:25 and activity 10:25–11:05** · Room 401-20 · Thomas Culino

The lecture introduces the ZTF and Rubin alert streams and BOOM, the alert broker that ingests both surveys. In the activity that follows, participants subscribe to live Babamul topics and write filters as Python functions that select candidates from ZTF and Rubin alerts.

Before the activity, copy `.env.example` to `.env` in this folder and fill in the three Babamul credentials from your profile page, as described in [`setup/README.md`](../../setup/README.md).
