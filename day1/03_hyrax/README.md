# Hyrax, machine learning in the LINCC ecosystem

**Monday November 9, lecture and demo 11:15–12:15 and hands-on 2:45–4:00** · Room 401-20 · Drew Oldag

The lecture introduces [Hyrax](https://github.com/lincc-frameworks/hyrax), the LINCC Frameworks framework for training and analyzing machine-learning models on survey data, with a short live demo. In the hands-on session, participants set up a Hyrax dataset of ZTF light curves and start training a light-curve model.

The model trained here is the starting point for the Day 2 similarity search session and for porting to Rubin DP2 in the Day 3 hackathon.
