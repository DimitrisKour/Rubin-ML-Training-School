# Similarity search in embedding space on ZTF alerts

**Tuesday November 10, 1:00–2:30** · Room 401-20 · Sneha Maharjan

This session covers nearest-neighbor search in the embedding space of a trained model. Participants build an index of ZTF alert embeddings, query it with a known transient, and use the returned analogs for discovery and classification.
