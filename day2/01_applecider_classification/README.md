# AppleCiDEr, multimodal classification of ZTF transients

**Tuesday November 10, 9:30–10:45** · Room 401-20 · Argyro Sasli

This session introduces [AppleCiDEr](https://github.com/applecider-ml/applecider), the multimodal transient classifier developed through the LINCC Incubator, which combines photometry, image cutouts, metadata, and spectra. Participants train and evaluate supervised classifiers for transients and variable stars on labeled ZTF alerts.
