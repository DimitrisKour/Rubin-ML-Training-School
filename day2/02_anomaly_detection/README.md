# Anomaly detection with AppleCiDEr and LUNA

**Tuesday November 10, 11:00–12:00** · Room 401-20 · Argyro Sasli

Following the morning lecture, participants score ZTF alerts for novelty with [LUNA](https://github.com/asasli/luna), the classifier-agnostic anomaly-detection library that combines uncertainty, distance, and density scores computed on AppleCiDEr embeddings and logits. Participants calibrate a threshold at a target false-alarm rate and rank the most anomalous candidates for follow-up.
